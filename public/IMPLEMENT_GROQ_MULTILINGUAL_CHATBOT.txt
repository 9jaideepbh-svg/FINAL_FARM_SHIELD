# IMPLEMENTATION: GROQ MULTILINGUAL AI CHATBOT (LLAMA 3)

## Objective
Enhance the existing Groq Voice AI Chatbot to support forced multilingual responses (all major Indian languages) based on a user-selected dropdown, regardless of the input language (text or voice). The AI (Llama model) must provide detailed, comprehensive answers rather than short replies.

---

## 1. UI & State Architecture
- **Language Dropdown Component**: 
  - Integrate a sleek, glassmorphic Shadcn UI dropdown menu in the chatbot header next to the mic icon (matching the provided reference image).
  - **Supported Languages**: English, Hindi (हिंदी), Kannada (ಕನ್ನಡ), Telugu (తెలుగు), Tamil (தமிழ்), Marathi (मराठी), Bengali (বাংলা), Gujarati (ગુજરાતી), Malayalam (മലയാളം), Punjabi (ਪੰਜਾਬી), Odia (ଓଡ଼ିଆ), and Urdu (اردو).
- **State Management**: 
  - Track `selectedLanguage` in React State.
  - Set default to "English (English)".
  - When the user taps the mic or starts typing, visually confirm the language being used.

---

## 2. Groq API & LLM Prompt Engineering
- **System Prompt Injection**:
  - The core of this feature relies on dynamic system prompt injection.
  - Update the `messages` array sent to `groq.chat.completions.create` to include a strict system instruction.
  - **Prompt Template**:
    ```text
    "You are a highly intelligent and expert agricultural AI assistant for Farm Shield. 
    CRITICAL INSTRUCTION: You MUST reply to the user EXCLUSIVELY in ${selectedLanguage}. 
    Even if the user asks a question in English or another language, your response MUST be in ${selectedLanguage}.
    Your answers must be highly detailed, elaborate, and comprehensive. Do not provide short or brief replies. Break down complex farming concepts into easy-to-understand but thorough explanations."
    ```

---

## 3. Voice / Audio Pipeline Integration
- **Speech-to-Text (Whisper)**:
  - When the user records voice, the audio is sent to Whisper (or similar STT) for transcription.
  - The transcription might return in the native language or English.
- **Enforcing Output**:
  - The transcribed text is passed to the Groq Llama model. 
  - Because of the strict System Prompt (Step 2), the Llama model will accurately translate and respond in the `selectedLanguage`, ensuring a seamless experience even if the user speaks in broken languages or mixed dialects.
