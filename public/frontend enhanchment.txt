## 1. FRAMER MOTION OPTIMIZATION

Find every Framer Motion usage in the project and apply 
these optimizations:

Add LazyMotion with domAnimation feature bundle to the 
root of the app to reduce Framer Motion bundle size by 
loading only what is needed:

import { LazyMotion, domAnimation } from "framer-motion"
Wrap the entire app with:
<LazyMotion features={domAnimation}>

Replace all motion.div with m.div after adding LazyMotion 
because m.div is the lightweight version that uses the 
loaded feature bundle instead of the full bundle.

For all animation variants add these performance hints:
- Add willChange: "transform" only on elements that 
  animate position or scale
- Add transform: "translateZ(0)" to force GPU layer 
  on heavy animated components
- Never add willChange to static elements

For all page transition animations:
- Use opacity and transform only
- Never animate width, height, top, left, margin, 
  or padding as these cause layout recalculation
- Replace any layout-affecting animations with 
  transform equivalents

Add layout={false} to any motion component that does 
not need layout animation to prevent unnecessary 
layout calculation on every render.

For AnimatePresence wrapping page transitions set 
mode="wait" and add initial={false} on the first 
render to skip entrance animation on page load.

## 3. CURSOR SPLASH EFFECT OPTIMIZATION

Find the ReactBits splash cursor component and apply:

Move the cursor canvas to its own React.memo wrapped 
component so it never re-renders due to parent state 
changes.

The canvas element must use position: fixed and 
pointer-events: none to avoid interfering with 
layout.

Use a single requestAnimationFrame loop for cursor 
rendering instead of multiple setInterval or 
setTimeout calls.

Throttle the mousemove event listener using 
requestAnimationFrame:
let rafId = null
window.addEventListener('mousemove', (e) => {
  if (rafId) return
  rafId = requestAnimationFrame(() => {
    updateCursorPosition(e.clientX, e.clientY)
    rafId = null
  })
})

Add will-change: transform to the cursor canvas 
element via CSS.

## 6. REACT RENDERING OPTIMIZATION

Audit the entire component tree and apply:

Wrap these components with React.memo to prevent 
unnecessary re-renders:
- Navbar component
- Footer component  
- Cursor component
- Background animation component
- Any card component that receives static props

For all useState hooks that trigger visual updates 
check if the state change actually changes what 
is rendered. Remove any state that is only used 
for tracking and does not affect the visual output.

Replace useState with useRef for values that change 
frequently but do not need to trigger re-renders such 
as cursor position, scroll position, animation 
frame counters.

Add useMemo to any expensive calculation that runs 
inside a render function.

Add useCallback to any function that is passed 
as a prop to a child component to prevent the 
child from re-rendering every time the parent renders.

Use React.lazy and Suspense for these pages since 
they are heavy and not needed on initial load:
- Crop Simulator page
- Soil Intelligence page
- Voice feature page
- History page
- Diagnosis page

Keep these as static imports because they are 
above the fold or navigation critical:
- Home page
- Navbar
- Landing components
