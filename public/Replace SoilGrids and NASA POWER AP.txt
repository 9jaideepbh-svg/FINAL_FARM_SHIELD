Replace SoilGrids and NASA POWER APIs completely

which are free and require no API key.

Use these 2 OpenMeteo endpoints:

Endpoint 1 - Soil Data:
https://api.open-meteo.com/v1/forecast?latitude={lat}&longitude={lon}&hourly=soil_temperature_0cm,soil_temperature_6cm,soil_moisture_0_to_1cm,soil_moisture_1_to_3cm,soil_moisture_3_to_9cm&forecast_days=7

This gives:
- Real time soil temperature at surface level
- Real time soil moisture at 3 different depths
- 7 day soil forecast

Endpoint 2 - Weather Data:
https://api.open-meteo.com/v1/forecast?latitude={lat}&longitude={lon}&daily=rain_sum,precipitation_probability_max,temperature_2m_max,temperature_2m_min,wind_speed_10m_max&forecast_days=7&timezone=Asia/Kolkata

This gives:
- Daily rainfall for next 7 days
- Max rain probability per day
- Temperature range
- Wind speed

Both APIs need zero API keys and work instantly 
for any Indian district coordinates.
