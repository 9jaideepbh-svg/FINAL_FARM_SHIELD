Rebuild the Soil Analysis page completely with 
this new architecture:

When user opens the page, automatically fetch 
their GPS location using browser geolocation API.
No manual input needed from the user.

After getting location coordinates call these 
APIs simultaneously:

1. SoilGrids API from ISRIC 
   URL: https://rest.isric.org/soilgrids/v2.0/
   properties/query
   No API key needed
   Get: soil pH, nitrogen, organic carbon, 
   clay percentage, sand percentage, 
   soil texture classification

2. NASA POWER API
   URL: https://power.larc.nasa.gov/api/temporal/
   daily/point
   No API key needed
   Get: soil moisture, soil temperature, 
   rainfall data

3. Tomorrow.io API (already in project)
   Get: rainfall forecast for next 7 days,
   humidity, temperature

After getting all 3 API responses send everything 
to Groq with this instruction:

weather data provided, generate a complete 
soil analysis report with:
- Soil type name and description
- Soil health score out of 100
- Top 5 best crops for this soil right now
- Fertilizer recommendations with NPK values
- Irrigation advice based on soil moisture
- Rain forecast impact on farming
- Soil improvement tips
- Warnings if any nutrient is deficient
